# jingxiangh.github.io

Personal academic website of **Jingxiang Huang** — PhD student in Economics at
The Chinese University of Hong Kong.

The site is plain HTML/CSS/JS with no build step, served by GitHub Pages
(the `.nojekyll` file disables Jekyll processing).

| File / folder         | What it is                                          |
| --------------------- | --------------------------------------------------- |
| `index.html`          | Home page: bio + research & working papers          |
| `cv.html`             | CV page (embeds `assets/HJX_CV.pdf`)                |
| `papers.js`           | **The data file for working papers — edit me**      |
| `styles.css`          | All styling                                         |
| `main.js`             | Renders `papers.js` + small page behaviors          |
| `assets/`             | PDFs (CV, papers)                                   |
| `images/`             | Photo and favicon                                   |
| `old-website-backup/` | Complete copy of the previous Jekyll site           |

**To update content, see [HOW_TO_UPDATE.md](HOW_TO_UPDATE.md).**
To restore the old design, see `old-website-backup/README_BACKUP.md`.
